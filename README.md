# Colgate-Palmolive Production Efficiency Optimization

This project focuses on improving the production efficiency of Colgate-Palmolive's manufacturing processes by identifying key bottlenecks and areas for optimization. Using Power BI, the project collects and analyzes operational data to provide actionable insights that help reduce downtime, improve throughput, and enhance overall efficiency.

## Project Overview

In this project, I developed a comprehensive Power BI dashboard to monitor and analyze the production performance at Colgate-Palmolive. The dashboard identifies operational inefficiencies such as low Overall Equipment Effectiveness (OEE), unplanned downtime, and capacity bottlenecks. By leveraging this data, we can optimize production schedules, reduce defects, and ultimately improve productivity across manufacturing lines.

## Key Features

- **OEE Analysis**: A detailed breakdown of Overall Equipment Effectiveness (OEE) across production lines, identifying areas with the most significant gaps in performance.
- **Downtime Analysis**: Identification of key causes for unplanned downtime, with visualizations to prioritize corrective actions and minimize machine idle time.
- **Capacity Utilization**: Real-time tracking of production capacity against demand, highlighting areas where adjustments can be made to increase throughput.
- **Defect Tracking**: Monitors production defects and inefficiencies, helping to focus improvement efforts on areas that will deliver the most cost-effective gains.
- **Real-Time Insights**: Dashboards updated in real-time to provide live feedback on production performance and support fast decision-making.
  
## Tech Stack

- **Power BI**: Used to create dynamic dashboards and reports for visualizing production metrics.
- **Excel / CSV**: Data sources were collected in Excel/CSV format from the company's internal systems and used for analysis.
- **DAX**: Data analysis expressions for creating custom calculations and measures in Power BI.
- **SQL**: Data extraction from internal databases for more refined, in-depth analysis.

## How It Works

1. **Data Collection**: Collect operational data from production lines including equipment performance, downtime records, and defect logs.
2. **Data Processing**: Clean and process the data using Power Query in Power BI to ensure consistency and accuracy.
3. **Dashboard Design**: Create a series of interactive dashboards to display key performance indicators (KPIs) such as OEE, downtime causes, and defect rates.
4. **Actionable Insights**: Provide actionable insights through the dashboards, allowing stakeholders to identify areas needing attention and implement corrective actions.
5. **Real-Time Monitoring**: Track production efficiency in real-time and send alerts when key thresholds are breached.

## Project Goals

The goal of this project is to improve the overall efficiency of Colgate-Palmolive's manufacturing processes by providing a clear view of production performance. By identifying inefficiencies such as downtime, defects, and capacity issues, the project allows the company to make data-driven decisions to increase productivity, reduce costs, and improve product quality.

## Results Achieved

- Identified key bottlenecks leading to 10-15% capacity loss.
- Proposed actionable solutions such as preventive maintenance scheduling and improved demand forecasting, which could lead to a potential 30% increase in production capacity.
- Delivered insights that helped reduce material defects by $1.12M annually.
- Reduced downtime by 20% through prioritization of key problem areas and resource reallocation.

## Future Improvements

- **Predictive Maintenance**: Incorporate machine learning models to predict failures before they occur and automate maintenance schedules.
- **Process Automation**: Further automate data collection and reporting processes to reduce human error and ensure real-time insights.
- **Cross-Plant Comparison**: Expand the dashboard to include cross-plant performance comparisons for benchmarking and continuous improvement.
- **Integration with IoT**: Integrate with IoT sensors for even more granular real-time data collection on equipment performance.

## Conclusion

This project significantly enhanced the production efficiency at Colgate-Palmolive by using Power BI to visualize key performance metrics. The actionable insights provided by the dashboards allow for quick, data-driven decisions that optimize the production process, reduce downtime, and increase throughput, ultimately improving the bottom line.
